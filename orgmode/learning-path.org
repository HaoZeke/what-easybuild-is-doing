Filenames keep a number to allow the source tree to sort.
That number does not indicate a reading order.
The page is the curriculum and contains hour-sized levels with named prerequisite edges.
A reader arrives with a task.
The map can be entered at any point.
The book consists of three parts, each represented by a page.
[[file:part-a-recipe.org][RecipeReader]] provides the file and the build.
[[file:part-a-stack.org][StackWalker]] provides a tree on a machine that may not have built it.
[[file:part-a-test.org][ReframeReader]] provides four kinds of testing, then ReFrame.
The levels are hour-sized entries into those parts.
Numbering does not represent the curriculum.

* ReframeReader
The official tutorial, the CSCS webinar, ExCALIBUR-tests and the EESSI suite each follow the same sequence.
The sequence consists of a test class, the pipeline, the configuration file, a performance number, and the portable suite.
There are two levels.
The grain matches the recipe.
