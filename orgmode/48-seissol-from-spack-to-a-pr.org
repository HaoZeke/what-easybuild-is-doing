#+begin_solution
1. Both. Inspect the Spack file for constraints. Bump the existing
 easyconfig for the next generation and version. The Spack file
 is not the file EasyBuild will build.
2. =package bump --version 1.7.0=. The ImpalaJIT line is a floor
 the old recipe still carries. It has to be dropped by hand, or
 the bump searches for ImpalaJIT on the new generation and

3. =package plan= from the GitHub sources, or a short
 =PythonPackage= written by hand. There is nothing to bump.
4. =eb=, or the site wrapper that is =eb= on that machine.
 =recipe check= is not a build.
#+end_solution
#+end_exercise

* Two defects the first build named
** The patch that was no longer the patch
The first =eblocalinstall= failed on ASAGI.
EasyBuild hashed the file next to the recipe and compared it to =da8c1c8c...=.
The file on disk hashed to something else.
A paste through a narrow terminal had wrapped the patch into a different byte string.

The repair is a fetch of the upstream patch, not a new hash of the broken file.

#+ATTR_EB: :id EB-SeisSol-2 :title Which claim failed
#+begin_exercise
Three failures. For each, name the claim that was false, and the
smallest change that makes the claim true.

1. =checksums= lists the hash of a recursive working tree. EasyBuild
 =git_config= hashes the tarball it packed.
2. =sanity_check_commands= runs =python -c "import pspamm"= through
 the default =PythonPackage= import.
3. The recipe toolchain is =foss/2026.1=. The node has
 =module load 2025= and =foss/2025a=.

#+begin_solution
1. The checksum named the wrong archive. Inject with
 =eb --inject-checksums= on the EasyBuild host, or hash the
 =git_config= tarball EasyBuild wrote. Do not keep the working-tree
 hash.
2. The import name is =pypspamm=. Set
 =options = {'modulename': 'pypspamm'}=. Leave the
 =pspamm-generator= sanity command.
3. The generation is not on the node. Retarget to =foss/2025a=.
 A 2026.1 recipe is a different consume, not a fix of this one.
#+end_solution
#+end_exercise

#+begin_keypoints
- A Spack recipe and an old easyconfig together are inspect plus
 bump, not a blank =package plan=.
- The generation is the one the site module environment already
 built. Newest-on-develop is a different consume.
- =eblocalinstall= is the install on Snellius. Raw =eb= with
 hand-set prefixes is the clash the tutorial names.
- A checksum names one archive. A PythonPackage import names one
 module. Neither is the EasyBuild software name.
