A stack forms a tree of modules on a machine that may never have built them.
EESSI is one such tree.[fn:eessi]
CernVM-FS provides the mechanism by which it arrives.[fn:cvmfs]
A site stack resides alongside it.
This part describes the arrival: the stratum, the bot, the easystack file, and the host injection.
