Part 2

A stack forms a tree of modules on a machine that may never have built them.
EESSI is one such tree.
CernVM-FS provides the mechanism by which it arrives.
A site stack resides alongside it.
This part describes the arrival: the stratum, the bot, the easystack file, and the host injection.
[[file:11-eessi-somebody-elses-stack.org][EESSI, somebody else's stack]] is the first read when the machine lacks its own software.
