Part 1

An easyconfig is a file.
EasyBuild evaluates the easyconfig, selects an easyblock, resolves a toolchain, and writes a module.
The file defines a pin.
The file defines the robot search.
The file defines a sanity check.
The file defines build execution.
The file defines recipe creation when none exists.
Start with the [[file:00-tutorial-read-an-easyconfig.org][tutorial]].
The tutorial takes about twenty minutes.
Installation is not required.
Four entries are presented instead of thirty pages.
