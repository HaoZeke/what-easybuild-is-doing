A module that loads is not a module that ran the workload.
[[file:23-testing.org][Testing, and the four things it can mean]] names four kinds of testing.
The fourth kind is ReFrame.
ReFrame is a decorated class.
ReFrame is a six-stage pipeline.
ReFrame is a configuration file that is the machine.
CSCS teaches ReFrame as its own course.
This part also teaches ReFrame.
Start at [[file:39-a-reframe-test-is-a-class.org][A ReFrame test is a class]].
This step assumes that Testing, and the four things it can mean has already been read.
